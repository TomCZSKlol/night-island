# NIGHT ISLAND — COMPLETE BUILD
Kompletní nový webový prototyp hry NIGHT ISLAND.

## Spuštění
Otevři `index.html` v moderním prohlížeči. Pro načtení 3D knihovny Three.js je potřeba internetové připojení.

- Počítač: WASD pohyb, myš pro kameru, mezerník skok, kliknutí střelba.
- Mobil: levý joystick, tažení pravou stranou obrazovky pro kameru, tlačítka SKOK a PALBA.

## Publikování přes GitHub Pages
1. Rozbal ZIP a nahraj všechny soubory do kořene svého GitHub repozitáře.
2. V repozitáři otevři Settings → Pages.
3. Zvol Deploy from a branch, větev `main`, složku `/(root)` a potvrď Save.
4. Po dokončení publikace otevři adresu GitHub Pages svého repozitáře.

## Důležité
Jde o single-player prototyp proti botům, nikoli o online multiplayer. Herní prostředí a postavy jsou vytvořené z jednoduchých 3D tvarů.
